# OOP1_Inl_KajensBikeRental

Högst upp när programmet startar finns två kundnummer som går att använda för att testa hyra cyklar.
Alternativt registrera en ny kund och spara kundnumret!
OBS! Kundnumren är randomgenererade så de blir olika varje gång programmet startar.

En PDF med reflektion och skrivdelen av inlämningen finns med i projektet.
